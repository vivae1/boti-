# 55 סגנונות של Motion Graphics

גלריית וידאו בעברית (RTL) עם 55 סגנונות מושן גרפיקס. כל כרטיס מנגן לולאה קצרה שמדגימה את הסגנון, ולחיצה עליו פותחת נגן עם ציר זמן, שליטה במהירות, מעבר פריים-פריים, והסבר: מתי להשתמש בסגנון, איך בונים אותו ובאילו כלים.

ההדגמות מצוירות בקוד (Canvas) בזמן אמת. אין קובצי וידאו, אין תלויות ואין שלב build.

## הרצה

- מקומית: פותחים את `index.html` בדפדפן.
- ב-Vercel: התיקייה מוגשת כקבצים סטטיים בכתובת `/motion-graphics/`.
- קישור ישיר לסגנון: `index.html#glitch` פותח את הנגן על הסגנון הזה.

## קבצים

| קובץ | תפקיד |
| --- | --- |
| `index.html` | המבנה והעיצוב (בהיר וכהה) |
| `data.js` | התוכן: 55 הסגנונות, 8 קטגוריות, טקסטים בעברית |
| `renderers.js` | פונקציית ציור אחת לכל סגנון, `draw(g, w, h, t)`, תלויה בזמן בלבד |
| `app.js` | הגריד, הסינון, הסרגל והנגן |

## הוספת סרטון אמיתי לסגנון

מוסיפים לסגנון ב-`data.js` שדה `video` עם קישור ליוטיוב או לקובץ `.mp4` / `.webm`:

```js
{ id: 'glitch', he: 'גליץ׳', /* ... */ video: 'https://www.youtube.com/watch?v=XXXXXXXXXXX' },
```

בנגן תופיע לשונית "סרטון" ליד ההדגמה החיה.

## הוספת סגנון חדש

1. מוסיפים רשומה ל-`STYLES` ב-`data.js` עם `id` חדש.
2. מוסיפים ב-`renderers.js` פונקציה בשם זהה: `R['my-style'] = (g, w, h, t) => { ... }`.
   `t` הוא הזמן בשניות בתוך הלולאה (`0` עד `dur`). כדאי לבנות את התנועה ממחזורים שלמים כדי שהלולאה תיסגר בלי קפיצה.
